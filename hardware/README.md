# Hardware

**`3d-print/`** — the enclosure. STLs in `stl/`, the Fusion 360 source as
`Simpsons_TV.f3d`, and renders and build photos in `images/`. `THINGIVERSE.txt`
is the original author's description, including print orientations and the
wiring notes worth reading before you start.

Print the front face down (the grill is a separate part so it needs no support).
The VCR and the volume knob are the only pieces that want support.

This is not my model — it's [The Simpsons TV (Remixed for HDMI display)](https://www.thingiverse.com/thing:5019648)
by highping, CC BY. See `LICENSE.txt`.

**`datasheets/`** — vendor documentation for the two boards that needed it:
the Waveshare UPS HAT (D) and the Adafruit MAX98357 I²S amp.
